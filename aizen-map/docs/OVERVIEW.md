# Project Overview

[Documentation index](README.md) · [Project README and screenshots](../README.md)

Aizen Map is a responsive Bengaluru discovery website for browsing sourced places and curated activities through a connected feed and map. The project demonstrates frontend work with Next.js 15, React 19, TypeScript, Tailwind CSS 4, custom CSS, Leaflet, OpenStreetMap, and Lucide icons.

Visitors can search by place or neighbourhood, filter listings, inspect details, open directions, save favourites, and switch between light and dark mode. Desktop uses a collapsible sidebar and paired feed/map layout; mobile offers a navigation drawer and a feed/map switch.

The current product is a curated preview. It has no user accounts, booking system, database, event-discovery API, or required API keys. No upcoming dated events are included in the active local data at this documentation review. Permanent venues and source shortcuts remain available.
